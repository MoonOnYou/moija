# 모이자 — 당기기 새로고침 + 시간순 정렬 + 모임 데이터 추가 설계

작성일: 2026-05-21
대상: 홈 모임 리스트(당기기 새로고침·시간순 정렬) + 목 데이터 확충
고정 "오늘": 2026-05-16 (앱 내 기준일)

## 목표

1. 홈 모임 리스트를 아래로 당기면 새로고침(스피너 + 재조회).
2. 모임 리스트를 시간대(시작 시각) 순으로 정렬.
3. 이번달(5월 후반)·다음달(6월)에 다양한 카테고리·장소·시간대의 모임을 추가해 필터 테스트를 쉽게.

## 1. 시간순 정렬 (`meeting_repository.dart`)

- `meetingsOn(day)`이 결과를 `startTime` 오름차순으로 정렬해 반환. 리스트와 달력 칩 모두 이른 시각부터.
- 영향: `meeting_repository_test`의 순서 의존 단언 갱신(5/19은 19:00 "코노 1시간"이 첫 항목).

## 2. 당기기 새로고침 (`day_meetings_pager.dart`, `home_screen.dart`)

- `DayMeetingsPager`에 `Future<void> Function()? onRefresh` 추가. 제공되면 각 페이지를 `RefreshIndicator`로 감싼다.
- 각 페이지의 스크롤뷰는 `AlwaysScrollableScrollPhysics`를 써서 짧은 목록·빈 날에도 당김 가능. 빈 날도 `ListView`로 구성해 당김 허용.
- 홈은 `_refresh()` 제공: `await Future.delayed(~400ms)` 후 `mounted`면 `setState`(현재 날짜 모임 재조회·필터 재적용). 목 데이터라 내용은 동일하지만 제스처·스피너 동작. (백엔드 연결 시 실제 패치 지점)

## 3. 모임 데이터 추가 (`meeting_repository.dart`)

- 5/21~6/28에 약 25개 모임 추가. 제약:
  - **기존 테스트가 의존하는 날짜는 건드리지 않는다**: 5/16(모임 2개), 5/17(주말 관악산 등반), 5/19(길이 2)에는 추가하지 않음.
  - 모든 카테고리(방탈출·볼링·노래방·술 한잔·카페·등산·수영·보드게임·롤·기타) 최소 1회 등장.
  - 다양한 장소 노드: 서울 호선, 부산/대구/광주/대전 호선, 경기·강원·경남 시, 인천 호선, 제주 등.
  - 다양한 시간대: 오전/오후/저녁/밤 골고루.

## 테스트

- `meeting_repository_test`: (a) 같은 날 여러 모임이 `startTime` 오름차순 정렬됨(예: 5/20), (b) 5/19 first=코노·length 2 유지.
- `day_meetings_pager_test`: 리스트를 아래로 당기면 `onRefresh` 콜백 호출.
- 기존 테스트(home_screen 등): 제목 존재 위주라 정렬·추가에도 통과. 5/16/5/17/5/19 불변으로 카운트·특정 단언 유지.

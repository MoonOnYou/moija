# 모이자 — 전국 장소 카탈로그 확장 설계

작성일: 2026-05-20
대상: `LocationCatalog` 데이터(대표 서브셋 → 전국 전체)

## 배경

기존 카탈로그는 대표 서브셋이라 경기·전라·강원·경남·충북 등에 빠진 시/군이 많았다. 전국을
빠짐없이 채운다.

## 결정 사항

- **시/도 17개 전체**: 서울·부산·대구·인천·광주·대전·울산·세종·경기·강원·충북·충남·전북·전남·경북·경남·제주. (기존 "전라" → 전북/전남 분리)
- **광역시**: 지하철 있으면 호선, 없으면 구/군.
  - 서울 1~9호선, 부산 1~4호선, 대구 1~3호선, 인천 1·2호선, 광주 1호선, 대전 1호선.
  - 울산: 중구·남구·동구·북구·울주군. 세종: 세종시.
- **도(道)**: 모든 시·군 포함.
- API(`regions`/`nodesIn`/`nodeById`)·`MeetingFilter`·화면은 그대로. **데이터만 확장**.
- 기존 모임 태그 `seoul-line2`는 서울에 그대로 존재 → 재매핑 불필요.

## id 규칙

- 지하철: `seoul-line1`..`seoul-line9`, `busan-line1`..`busan-line4`, `daegu-line1`..`daegu-line3`, `incheon-line1`/`incheon-line2`, `gwangju-line1`, `daejeon-line1`.
- 울산 구/군: `ulsan-junggu`, `ulsan-namgu`, `ulsan-donggu`, `ulsan-bukgu`, `ulsan-uljugun`.
- 세종: `sejong` (label "세종시").
- 도의 시·군: `<도>-<시군>` (예: `경기-수원시`, `강원-고성군`, `경남-고성군`). 같은 이름(고성군 등)을 도 접두로 구분.

## 도별 시·군 (전수)

- 경기(31): 수원·성남·의정부·안양·부천·광명·평택·동두천·안산·고양·과천·구리·남양주·오산·시흥·군포·의왕·하남·용인·파주·이천·안성·김포·화성·광주·양주·포천·여주 시 + 연천·가평·양평 군.
- 강원(18): 춘천·원주·강릉·동해·태백·속초·삼척 시 + 홍천·횡성·영월·평창·정선·철원·화천·양구·인제·고성·양양 군.
- 충북(11): 청주·충주·제천 시 + 보은·옥천·영동·증평·진천·괴산·음성·단양 군.
- 충남(15): 천안·공주·보령·아산·서산·논산·계룡·당진 시 + 금산·부여·서천·청양·홍성·예산·태안 군.
- 전북(14): 전주·군산·익산·정읍·남원·김제 시 + 완주·진안·무주·장수·임실·순창·고창·부안 군.
- 전남(22): 목포·여수·순천·나주·광양 시 + 담양·곡성·구례·고흥·보성·화순·장흥·강진·해남·영암·무안·함평·영광·장성·완도·진도·신안 군.
- 경북(22): 포항·경주·김천·안동·구미·영주·영천·상주·문경·경산 시 + 의성·청송·영양·영덕·청도·고령·성주·칠곡·예천·봉화·울진·울릉 군. (군위군은 2023년 대구 편입으로 제외)
- 경남(18): 창원·진주·통영·사천·김해·밀양·거제·양산 시 + 의령·함안·창녕·고성·남해·하동·산청·함양·거창·합천 군.
- 제주(2): 제주시·서귀포시.

## 테스트

- `location_catalog_test` 갱신:
  - `regions.length == 17`, 첫 번째 `서울`, `전북`·`전남` 포함, `전라` 미포함.
  - `nodesIn('서울').length == 9`, `nodesIn('제주').length == 2`.
  - `nodesIn('경기')`가 수원시·양평군 포함 & 길이 >= 31.
  - `nodeById('seoul-line2')?.label == '2호선'`, `nodeById('경기-수원시')?.label == '수원시'`, `nodeById('busan-line4')?.label == '4호선'`.
  - 같은 라벨(고성군)이 강원/경남 양쪽 노드로 서로 다른 id로 존재.
